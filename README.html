How entries connect

An invoice links to a customer and optionally a product. A product invoice reduces available stock and captures the current unit cost. Payments link to an invoice and cannot exceed its remaining balance. A received purchase order adds units; a paid purchase order reduces calculated cash. Expenses, payroll and manual tax entries use Paid flags for cash movement.

Read the reports correctly

Profit & loss uses invoiced sales excluding invoice tax, saved sale-time product costs, logged expenses and gross payroll. The cash view starts with your opening cash and adds received payments, then subtracts cash marked paid. The balance snapshot adds calculated cash, invoice receivables and inventory at current unit cost; it shows selected liabilities and a balancing equity difference.

This is a simplified organization tool. It does not keep a full double-entry ledger, issue legally compliant invoices, file taxes, calculate payroll obligations or replace bookkeeping and accounting advice. Review figures with a qualified professional.

Personalize

Settings has five light themes, modern/serif/large fonts, compact/comfortable/spacious density, soft/flat cards, high contrast and an appearance reset. Currency selection changes the display symbol, not saved values. English, Spanish, French and German change navigation and key labels; detailed explanations and your typed entries stay as entered.

Backup, transfer and privacy

All data stays in this browser profile and device. Export a JSON backup regularly. Copy that backup to another device and import it there; the import replaces current records after confirmation. Clearing site/browser data can erase local records. There is no automatic sync, shared login or cloud database.

Offline and phone use

The extracted download works offline on desktop. For a phone home-screen icon, the customer files need separate HTTPS hosting. Safari: Share → Add to Home Screen. Chrome: Install app/Add to Home Screen when available. A separately hosted demo contains fictional data and is not your private account. On supported HTTPS hosts, the app shell can be cached for offline use after the first load.

Common fixes

Blank records: Check the same browser/profile and URL; import your last backup. Download looks like code: Extract ZIP and open index.html. Import fails: Use an unmodified Cedar Ledger JSON backup. Home-screen option missing: Use HTTPS and a current browser. Numbers seem unexpected: Review dates, Paid and Received flags, opening balances and all linked invoices/payments.
